## Projetos em destaque

### FinanceOS

Sistema de gestão financeira pessoal desenvolvido para centralizar, processar e analisar informações financeiras.

**Tecnologias:**
Python • Streamlit • PostgreSQL • Supabase • Pandas • Plotly • Docker • Cloudflare

**Principais recursos:**

* Importação de faturas e documentos em PDF, Excel e CSV
* OCR para extração de informações de documentos
* Dashboards e análises financeiras interativas
* Autenticação e separação de dados por usuário
* PostgreSQL com políticas de segurança RLS
* Testes automatizados
* Deploy em nuvem

---

### InfraOS

Dashboard desenvolvido para auxiliar no monitoramento, inventário e gerenciamento de infraestrutura Windows.

**Tecnologias:**
Python • Streamlit • Pandas • WMI • PowerShell • PyWin32 • ThreadPool

**Principais recursos:**

* Inventário automatizado de computadores
* Coleta remota de informações via WMI
* Verificação de disponibilidade dos equipamentos
* Processamento paralelo de máquinas
* Organização de equipamentos, setores e patrimônios
* Interface web para administração e visualização dos dados

**Observação:** este projeto é apresentado como case técnico. Dados, credenciais e informações internas do ambiente corporativo não são disponibilizados publicamente.

---

### Sistema de Deploy

Aplicação desktop desenvolvida para automatizar a preparação de máquinas, configurações do Windows e instalação de softwares.

**Tecnologias:**
C# • .NET • WPF • XAML • Windows APIs • Async/Await

**Principais recursos:**

* Automação da instalação de softwares
* Detecção de aplicações através do Windows Registry
* Execução assíncrona de processos
* Configuração de serviços do Windows
* Verificação de privilégios administrativos
* Geração de logs
* Distribuição self-contained para Windows x64
